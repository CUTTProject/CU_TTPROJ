Getting started

Register your school, sign in, and check that everything is working. This takes about five minutes.

1. Register your school

Each school has one admin account. Its email and password are what you'll sign in with.

curl -X POST https://your-server/api/schools/create \
  -H "Content-Type: application/json" \
  -d '{
    "schoolName": "Example University",
    "schoolAddress": "1 University Road",
    "schoolPhone": "+234 800 000 0000",
    "schoolAdminEmail": "timetable@example.edu",
    "schoolAdminPassword": "Strong@Pass2026",
    "schoolDayStartHour": "08:00",
    "schoolDayEndHour": "17:00",
    "schoolBreakStartHour": "12:00",
    "schoolBreakEndHour": "13:00"
  }'

About the times

  • School day: classes are only placed between the start and end hours, Monday to Friday.
  • Break: nothing is ever scheduled during it. It must fall inside the school day.
  • Use 24-hour time, HH:mm.

The password needs at least 8 characters, with an uppercase letter, a lowercase letter, a number and one of @ $ ! % * ? &. No other characters are allowed, including spaces, hyphens and #.

2. Sign in

curl -X POST https://your-server/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "timetable@example.edu",
    "password": "Strong@Pass2026",
    "loginType": "SCHOOL"
  }'

The response contains an authToken:

{
  "school": { "schoolName": "Example University", ... },
  "authToken": "eyJhbGciOiJIUzI1NiJ9..."
}

3. Use the token

Every other request must include the token in an Authorization header. To save typing, store it in your terminal session once:

export BASE=https://your-server
export TOKEN=eyJhbGciOiJIUzI1NiJ9...

The rest of these docs use $BASE and $TOKEN.

Tokens expire after one hour. If requests suddenly return 403 with an empty body, sign in again and update TOKEN.

4. Check where you are

The onboarding guide lists every setup step in order, and shows which ones your school has finished and which one to do next:

curl $BASE/api/onboarding/guide -H "Authorization: Bearer $TOKEN"

Each step tells you its CSV and JSON endpoints, the fields it accepts, what it depends on, and whether it's completed and ready. You can come back to it at any point during setup.

Prefer clicking to typing? Open the API reference, click Authorize, paste your token, and use Try it out on any endpoint.
