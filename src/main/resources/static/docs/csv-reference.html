Data fields

Every field each upload accepts, for CSV and JSON alike. Bold fields are required.

Each name below is both a CSV column and a JSON key. Spell it exactly as shown, including capital letters. Fields you don't need can be left out.

The first row is the field names, and each following row is one record. Column order doesn't matter.

roomNumber,roomBuilding,roomCapacity,roomType
LT1,Engineering Block,200,LECTURE_THEATRE
Lab-2,Science Block,40,LAB

Each record is an object in rows. Key order doesn't matter. Numbers can be JSON numbers, and everything else is a string, including yes/no values.

{
  "rows": [
    { "roomNumber": "LT1", "roomBuilding": "Engineering Block",
      "roomCapacity": 200, "roomType": "LECTURE_THEATRE" },
    { "roomNumber": "Lab-2", "roomBuilding": "Science Block",
      "roomCapacity": 40, "roomType": "LAB" }
  ]
}

For sections and enrollments, also send "academicPeriodId" next to rows.

Departments

FieldNotes
departmentCodeShort code, up to 20 characters, e.g. CSC. Used to match rows on re-upload.
departmentNamee.g. Computer Science
departmentHeadStaffNumberA lecturer's staff number. Leave blank until lecturers are uploaded.

Lecturers

FieldNotes
lecturerStaffNumberUnique per lecturer, e.g. L001.
departmentCodeMust match an uploaded department.
lecturerFirstName, lecturerLastNameOptional. Without a name, the staff number is shown on the timetable.
lecturerEmailOptional.

For names and emails, an empty cell clears the stored value, while a missing column leaves it unchanged. The same applies to students.

Sections

Uploaded into an academic period. One row per class group.

FieldNotes
courseCodeAn uploaded course.
sectionNamee.g. CSC 101-CSC. Used by enrollments.
lecturerStaffNumbersOne or more, separated by /, e.g. L001/L002.
sectionDurationMinutesTotal teaching time per week, a multiple of 5, e.g. 180.
eventTypeCLASS or LAB. A label only.
sectionEnrollmentSizeExpected number of students. Used to pick a big enough room.
sectionUnitsOverrides the course's units for this section.
splityes, no (default) or maybe. See below.
relatedToAnother section's name, to teach the two together. See below.
roomsOnly use these rooms, e.g. LT1/LT2. Blank means any suitable room.
timeslotOnly use these times, e.g. M(13:00-15:00)/TH(14:00-17:00).

Splitting a section into meetings

  • split=no: the section meets once a week for its full duration.
  • split=yes: a 3-unit section meets twice, for ⅔ and ⅓ of its time. A 4-unit section meets twice, for half its time each. Other unit counts can't be split.
  • split=maybe: the scheduler decides each time it generates, whichever fits better.

Teaching two sections together

If two groups share one class, for example Physics students and Computer Science students taking PHY 107 together, set relatedTo on PHY 107-CSC to PHY 107-PHY. They're placed at the same time in a room that seats both, and shown as PHY 107-CSC/PHY 107-PHY. This works for pairs only.

Day codes for timeslot

M or MON, T or TUE, W or WED, TH or THU, F or FRI, plus SAT and SUN. Times use 24-hour HH:mm.

Enrollments

Uploaded into an academic period. One row per student per section.

FieldNotes
studentMatriculationNumberAn uploaded student.
courseCodeThe section's course.
sectionNameA section in this period.

Uploading an enrollment that already exists changes nothing, so it's safe to upload the full list again.
